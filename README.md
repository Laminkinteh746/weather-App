# weather-App
This is a lightweight weather application that displays current conditions from OpenWeatherMap.

## Files

- `index.html` - Application markup and JavaScript.
- `style.css` - Application styles.

## Setup

1. Get an API key from [OpenWeatherMap](https://openweathermap.org/api).
2. Open `index.html` and replace `YOUR_API_KEY` in the script with your key.
3. Open `index.html` in a browser, or serve the folder with a local web server.

Enter a city name and select **Get weather**. The app displays the city, current temperature, weather description, and humidity.
